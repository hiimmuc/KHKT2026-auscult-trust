# Documentation

| Path | Content |
| --- | --- |
| `../report.md` | Results by stage (read first) |
| `SETUP.md`, `REPRODUCE.md` | Environment and data; commands per stage |
| `registered/` | Pre-registration v8, amendments 1-5, proposals v9 (registered) and v10 (current). Do not edit |
| `plans/` | Stage plan (grid), LODO plan, target-evaluation plan, distillation plan |
| `decision-logs/` | Decisions that bind later work: dB scale, final model (23/10), distilled model (29/10) |
| `reports/` | Detailed tables behind `report.md`: grid, LODO, ensembles, frozen evaluation, target + distillation, replay |
| `handoff/HANDOFF.md` | Current state, written when a session runs out of context |

Names: `YYYY-MM-DD-topic.md`, lower-case kebab-case. New results go into `../report.md` first; a detailed report only when the tables do not fit.
Claims carry a tag: [Fact], [Interpretation], [Assumption], [Pending].

Removed material (phase-0 ladders, audits, stage-12 trial reports, older decision logs and handoffs) is archived outside the repo at
`/storage/hdd/disk0/namdp15/auscult-trust-archive/`; git history holds the tracked files.
