# Documentation

| Path | Content |
| --- | --- |
| `../report.md` | Results by stage (read first) |
| `SETUP.md`, `REPRODUCE.md` | Environment and data; commands per stage |
| `registered/` | Pre-registration v8, amendments 1-5, proposals v9 (registered) and v10 (current). Do not edit |
| `plans/` | Stage plan (grid), LODO plan, target-evaluation plan, distillation plan |
| `decision-logs/` | Decisions that bind later work: dB scale, final model (23/10), distilled model (29/10) |
| `reports/` | Tables behind `report.md`: grid, LODO, ensembles, frozen evaluation, target + distillation, replay |
| `handoff/HANDOFF.md` | Current state and open items |

Names: `YYYY-MM-DD-topic.md`, kebab-case. New results go into `../report.md` first. Claims carry a tag: [Fact], [Interpretation], [Assumption], [Pending].

Removed material (phase-0 ladders, audits, stage-12 trial reports, older decision logs) is in git history.
