## Sections

Use numbered `##` headings for long documents. Every number cites its source file (`outputs/...`, `build/campaigns/...`,
or another document). Keep negative results. Write in English; the one exception is
`reports/2026-10-27-improvement-results.md` (Vietnamese tables).
